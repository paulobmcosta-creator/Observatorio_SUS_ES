# Python/PySUS experimental

Esta pasta contém componentes Python/PySUS criados para investigação, prova de conceito e mapeamento estrutural do CNES.

A trilha Python/PySUS é experimental/prototípica, não é pipeline produtivo e não autoriza geração de bases. A Etapa 5N foi encerrada com ressalvas: PySUS/CNES mostrou viabilidade parcial para acesso e mapeamento, mas ST permanece instável/intermitente, `CO_UNIDADE` não foi resolvido e R permanece como oráculo metodológico.

Alunos não devem executar ou modificar estes componentes sem autorização explícita.
