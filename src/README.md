# Código-fonte do Observatório SUS-ES

Esta pasta contém código-fonte do pipeline e componentes metodológicos do Observatório SUS-ES, com destaque para rotinas R relacionadas ao piloto CNES.

O conteúdo deve ser tratado como legado/oráculo metodológico e não deve ser alterado por aluno sem orientação. Leituras supervisionadas podem ser úteis para compreender o pipeline, mas execução, refatoração ou substituição de scripts dependem de autorização explícita.
