# Guias do aluno — Observatório SUS-ES

## 1. Finalidade

Esta pasta é a entrada pedagógica do aluno no Observatório SUS-ES. Ela organiza uma leitura inicial segura, progressiva e supervisionável, separando o núcleo atual do projeto de documentos históricos, scripts técnicos e áreas restritas de dados.

O objetivo é permitir que o aluno compreenda o projeto antes de executar qualquer código, alterar arquivos ou propor mudanças metodológicas.

## 2. Ordem de leitura

1. `guia_inicio_observatorio_sus.md`
2. `mapa_repositorio_observatorio_sus.md`
3. `glossario_minimo_cnes_observatorio.md`
4. `plano_trabalho_aluno_cnes.md`
5. Documentos CNES indicados pelo orientador

## 3. Regras de segurança

- Não executar scripts sem autorização.
- Não alterar scripts.
- Não alterar metadados.
- Não alterar dados.
- Não gerar bases.
- Não mexer em `CO_UNIDADE`.
- Não substituir R.
