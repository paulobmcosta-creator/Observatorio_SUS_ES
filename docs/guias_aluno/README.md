# Guias do aluno — Observatório SUS-ES

## 1. Finalidade

Esta pasta é a entrada pedagógica do aluno no Observatório SUS-ES. Ela organiza uma leitura inicial segura, progressiva e supervisionada pelo orientador, separando o núcleo atual do projeto de documentos históricos, scripts técnicos e áreas restritas de dados.

O objetivo é permitir que o aluno compreenda o projeto como revisor humano assistido antes de executar qualquer código, alterar arquivos ou propor mudanças metodológicas. Nesta fase, a contribuição esperada é ler, fichar, levantar dúvidas, identificar ambiguidades e ajudar a tornar a documentação mais clara.

## 2. Ordem de leitura

1. `guia_inicio_observatorio_sus.md`
2. `mapa_repositorio_observatorio_sus.md`
3. `glossario_minimo_cnes_observatorio.md`
4. `plano_trabalho_aluno_cnes.md` — roteiro de revisão humana assistida, sem prazo rígido
5. Documentos CNES indicados pelo orientador

## 3. Regras de segurança

- A revisão é assistida pelo orientador e não autoriza execução autônoma.
- Não executar scripts sem autorização expressa.
- Não alterar scripts.
- Não alterar metadados.
- Não alterar dados.
- Não gerar bases.
- Não mexer em `CO_UNIDADE`.
- Não substituir R.
- Registrar dúvidas e inconsistências percebidas em vez de corrigir diretamente arquivos técnicos.
