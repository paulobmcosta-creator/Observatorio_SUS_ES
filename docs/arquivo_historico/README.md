# Arquivo histórico — Observatório SUS-ES

## 1. Finalidade

Esta pasta preserva documentos históricos, diagnósticos técnicos e decisões metodológicas que fizeram parte da construção do Observatório SUS-ES. O material aqui arquivado é importante para rastreabilidade científica, mas não deve ser usado como material inicial de orientação do aluno.

A separação entre documentação pedagógica e documentação histórica evita que leitores iniciantes confundam registros de investigação, hipóteses já superadas, diagnósticos de erro ou deliberações intermediárias com instruções operacionais atuais.

## 2. Regra de uso

- Consultar apenas quando houver necessidade de rastreabilidade metodológica ou técnica.
- Não usar como instrução operacional para execução de pipeline.
- Não entregar inicialmente ao aluno sem mediação do pesquisador ou orientador.
- Não apagar sem decisão explícita do pesquisador responsável.
