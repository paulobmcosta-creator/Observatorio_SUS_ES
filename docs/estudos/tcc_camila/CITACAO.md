# Como citar a edição científica

**Desenvolvimento técnico:** COSTA, Paulo Borges Mathias. *Observatório SUS-ES: código e dados derivados do estudo cardiovascular, Espírito Santo, 2014–2024*. Instituto Federal do Espírito Santo, versão 3.5.1-preview (não publicada). Registro provisório para revisão local, sem DOI e sem URL de release confirmado.

**Trabalho de conclusão:** SANTOS, Camila Moreira dos. *Modelo analítico para avaliação da atenção cardiovascular especializada no Espírito Santo: oferta, utilização assistencial e mortalidade como subsídios à gestão em saúde*. TCC, versão acadêmica em revisão; confirmar título, instituição e ano da edição final antes de citar formalmente.

As referências têm finalidades diferentes: o projeto de código deve creditar quem o desenvolveu; a obra acadêmica tem autora própria; os dados oficiais seguem a atribuição de suas fontes. Não atribuir titularidade patrimonial exclusivamente a nenhuma dessas partes sem documentação.
