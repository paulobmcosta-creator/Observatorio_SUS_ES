# Scripts técnicos

Esta pasta contém scripts de apoio, legado/oráculo ou utilitários técnicos do Observatório SUS-ES.

Alunos não devem executar, alterar ou usar estes scripts como ponto de partida sem autorização explícita do pesquisador ou orientador. A execução indevida pode instalar dependências, alterar ambiente de trabalho ou produzir interpretações incorretas sobre o estado do pipeline.
