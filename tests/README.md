# Testes e validação técnica

Esta pasta contém testes automatizados, fixtures e validações técnicas do Observatório SUS-ES.

Os testes existem para proteger contratos, metadados, transformações e comportamento esperado do pipeline. Alunos não devem alterar testes, fixtures ou validações sem autorização explícita, porque mudanças nesta pasta podem mascarar regressões ou fragilizar a rastreabilidade metodológica.
